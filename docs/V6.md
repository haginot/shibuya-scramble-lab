## One command

```sh
tools/render_v6.sh check            # configs == generator, v6 validator (+ sources), reuse maps, every source file located + asserted
tools/render_v6.sh plan [<pair>]    # pieces + jobs (≤300-frame segments) with time estimates; fails if a job > 45 min
tools/render_v6.sh zone             # → /workspace/demos/halloween-escape-series/jr-v6/zone.mp4 + zone-contact.jpg
tools/render_v6.sh all              # gate taxi zone alt
tools/render_v6.sh stills zone 1.6,62|new     # body-second PNGs ('new' = every new / re-shot beat); AGENTS=8000 default
tools/render_v6.sh stills opening new         # the mission card
tools/render_v6.sh contact zone
SMOKE=1 tools/render_v6.sh gate     # no browser: new pieces not rendered yet = black; join/audio/mux/verify/accuracy/contact for real
MAX_SEGS=1 tools/render_v6.sh zone  # render one missing segment, exit 3 (re-run → next); the last run joins, mixes and verifies
```

Env:
- `OUT`: default `/workspace/demos/halloween-escape-series/jr-v6`.
- `WORK`: default `/workspace/projects/logs/ssl-claude-halloween/next/render`.
- `SRC`: the variant renders, read only.
- `COMBINED`: the combined renders `…/combined/render`, read only.
- `OPENING_MP4`: the pinned opening, 426 f.
- `SEG_FRAMES` (≤ 300), `MAX_SEGS`, `AGENTS`, `PR`, `PYBIN`, `CRF` (16), `X264_PRESET`, `BROWSER_LOCK`, `SMOKE`.

Every recorder call runs under `flock /tmp/ssl-halloween-browser.lock`.

What `<pair>` does (`$WORK/<pair>/`):
1. **Validate:** `node tools/variant_cues.mjs v6/<pair> --opening v6/_opening --check`.
2. **Reuse maps:** `--reuse-map v6/_opening` (shared, `$WORK/opening/map.json`) and `--reuse-map v6/<pair>`.
3. **Sources:** `tools/v6_pipeline.py sources` locates every source and asserts its frames, format and beat edges:
   - `_opening`: the pinned opening.mp4.
   - `<pair>-over|clear`: the variant `body-*/body.mp4`.
   - `combined/<pair>`: the combined episode's first-generation NEW pieces, exactly the files its final join used (from its
     `join.json`). Its `video.mp4` is used only as a flagged second-generation fallback.
4. **Render only the new pieces:**
   - The mission (opening frames 231–336) is rendered once and shared, in `$WORK/opening/opening-<key>/`.
   - Per pair: first-choice+true-end+guide (345 f), goodbye+sources (345 f), plus every re-shot beat.
   - Pieces are split into equal segments of ≤ 300 frames. One browser session per segment. Runs are resumable.
5. **Join:** one raw pipe into ONE libx264 encode (crf 16). Every piece's frame count is asserted.
6. **Audio:** `tools/audio/run.sh mix --strict --strict-lint` on the v6 cue sheet (opening + body, the opening is mastered as
   its own segment), then `mux.sh` (AAC 192k).
7. **Verify** (`report.json`):
   - frames 2646, `1080,1920,yuv420p,30/1`, `aac,48000,2`;
   - EBU R128 −15.5…−12.5 LUFS, true peak ≤ −1 dBTP;
   - PSNR accuracy of the first and last frame of every reused range against the source frame ±1;
   - contact sheet with every beat labelled: MISSION, first choice / A picked, TRUE END, guide, caught ×4, GAME OVER on
     black, CONTINUE? 3/YES, CLEAR, kaiju, GOODBYE in/full/end, sources, and `RE-SHOT <beat>` for each re-shot beat.

### Validator (`validateV6`, `validateV6Opening`, inside `validateConfig`)

Errors:
- beat order;
- a copied beat without `reuse`/`origin`, or with a source other than its allowed ones; a new beat with `reuse`;
- the first choice is not `card:true`, the prompt or options text is wrong, or A is not picked;
- true-end does not directly follow the first choice, does not have exactly one `TRUE_END` stamp, or has a crowd;
- TRUE_END outside true-end; GAME_OVER outside over-stamp; CLEAR kinds outside clear-stamp;
- header/clock rules (caught, kaiju, goodbye, cards); kaiju BGM;
- missing items; both runs picking the same option; the old `endcard`;
- goodbye text not verbatim (`V6_GOODBYE`; only line breaks may differ), our message carrying an attribution,
  stay-away wording (来るな/行かない/近づくな/don't go …) in the quoted city block or in any string that names the city;
  goodbye with the page footnote on or shorter than 8 s;
- invitation wording (会場 / 楽しも …) in a new beat. In a reused caption it is a warning for QA;
- the opening has a notice beat, the mission text is wrong, the issuer is not fictional, or the wording contains 「脱出ゲーム会場」.

With the source configs, also errors on: picks, source beats and durations, and `sources[]` ⊇ the union of both runs.
Video length: 75–95 s (`V6_VIDEO`; recorder `V6_RANGE`).
