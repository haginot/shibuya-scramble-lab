A fictional day around JR Asagaya Station, Tokyo

asagaya-town-sim

Explore a neighborhood in motion.

Compare a new café, a station event, a rainy day, and three possible uses of a station-side site with a small agent-based simulation.

View on GitHub · English guide · 日本語

A toy model, not a forecast. All behavior coefficients are assumptions. Residents and trips are fictional. Results do not predict real visits, sales, or foot traffic.

What you can explore

  • Residents, train visitors, and local commuters moving on an OpenStreetMap road network.
  • Four scenarios and a comparison of bicycle parking, a café, and a plaza.
  • Opening hours, spontaneous stops, walking distances, and station activity.
  • A Japanese-language animated map, comparison tables, and static HTML/JSON export.

Quick start

Requires Python 3.9+. In a local checkout:

python3 -m pip install .
asagaya-town-sim demo --no-llm
asagaya-town-sim serve --no-llm

The local viewer opens at http://127.0.0.1:8765/. The main package has no runtime dependencies. Viewing maps requires internet access. Optional LLM planning is configured separately through environment variables.

Export a precomputed viewer with asagaya-town-sim build --no-llm -o out. This page is an introduction; it does not run the simulation.
