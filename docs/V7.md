# JR編 v7 — CG → photoreal switch, original Showa-style kaiju, v6 QA fixes

v7 builds on v6 (`docs/V6.md`): same four videos (`gate`, `taxi`, `zone`, `alt`), same 88.2 s / 2646-frame timeline,
same beats, cues and TRUE END / GOODBYE end card. Briefs: `logs/ssl-claude-halloween/v7/brief.md`,
`STEERING-kaiju.md`, `STEERING-photoreal-switch.md` (HAGINO 2026-10-27).

## What changed
1. **CG → photoreal switching** (`tools/v7_plan.json`). Cold open, mission card, maps, TRUE END, kaiju and the end
   cards stay CG. Inside Shibuya — the rules card ("this is real Shibuya" reveal right after the mission card), first
   choice, guide, the walks, gate / street results, the caught sequence, lesson, CONTINUE?, CLEAR and the cheat sheet —
   is photoreal: a cleaned plate (AI-generated reference images from `grounded-refs/v2`, one CC0 photo by Syced), 2.5D
   parallax, procedural silhouettes for every person, grain, light motion blur, and the game HUD on top. Every cut
   between the two looks is an 8-frame RGB glitch (or a whip pan into a walk / result shot) with its own synth sound.
2. **Kaiju** (`web3d/shibuya/series/kaiju.mjs`): an original, stylised CG beast — black, hunched on four legs, long neck,
   beaked and horned head, glowing crystal-prism dorsal spines, a beam from the mouth up into the empty sky. It is not
   upright, has no tail and no leaf plates, and uses the project's own synth roar. The line 「えっ、ボス戦あるの!?」 is kept.
3. **v6 QA fixes**:
   - The gate over-move caption names 宮益坂口: 「改札前の通路は一方通行／宮益坂口側まで抜けてUターン／（2025年1月・2026年3月の報道）」.
     It is backed by fact JR-GATE-18 (JR East Tokyo Construction PMO X 2026-02-21, シブヤ経済新聞 2026-02-17).
   - The footnote has moved out of the TikTok/Reels caption and button zones. Its bottom edge is 266 px (20.8 %) and its right
     edge 112 px (15.5 %) on the 720×1280 CSS canvas (`ui/tokens.mjs` `ZONE.foot`, `FOOT_CLEAR`). Captions stack above it.
     The recorder asserts both limits on every frame.
   - The cheat-sheet footer no longer says 「※パロディ動画の要約です」.

## Pipeline
```sh
node tools/v7_configs.mjs --write            # v7 configs = v6 configs + plateTag, caption fix, kaiju size, credits
python3 tools/render_v7.py plan [pair]       # layer per frame range: cg / photo / v6
python3 tools/render_v7.py cg opening|<pair> # re-render CG pieces (≤300-frame segments, nice, browser lock, resumable)
python3 tools/render_v7.py hud opening|<pair># transparent HUD layer for photo beats (record_variant.py --hud-only)
python3 tools/v7_composite.py <pair>         # plates + silhouettes + HUD + CG/v6 frames + transitions → video.mp4
python3 tools/v7_composite.py <pair> --cuts  # the switch plan (frame, time, glitch|whip)
python3 tools/v7_finish.py all <pair>        # v7 cue sheet → mix (−14 LUFS) → mux → contact sheet → verify
```
- **HUD-only layer** (`app-variant.mjs` `&hudonly=1`, `record_variant.py --hud-only`): the WebGL view is hidden and the
  page is transparent. The shot env and crowd states are still evaluated, but nothing 3D is rendered. Each frame is one
  RGBA PNG. On photo beats the 「位置・構造は概略」 tag becomes the beat's `plateTag` (「AI生成画像を加工」 / 「写真 Syced／CC0」).
- **Plates** (`v7_composite.py` `GEOM`, cached in `$WORK/plates`, never committed):
  - brand logos, ads, AI-made sign text and number plates are blurred flat; big screens become unlit boards;
  - every person in a plate is blurred, darkened and desaturated, so no face is identifiable;
  - the procedural silhouettes (no faces, a few costume shapes) are drawn on top.
- **v6 frames** are used frame-exact where no footnote is on screen: the GAME OVER stamp on black, and the GOODBYE end card.
- **Audio** is the v7 cue sheet: the v6 cues, plus `glitch`/`whoosh` on every switch. The caught zombie groans are dropped,
  because no zombie is shown.
