阿佐ケ谷 町シミュレーション
Asagaya town simulation

仮説探索用トイモデル。予測ではありません。 住民・店舗（架空の「ひだまり珈琲」を含む）・売上・販促係数はすべて架空・仮置きです。OSM/GSI由来なのは地図形状・地形のみです。地名ラベルは出典情報です。

Toy model for hypothesis exploration, not a forecast. All residents, simulated stores (including fictional Hidamari Coffee), sales and promotion coefficients are fictional/placeholders. Only map geometry and terrain come from OSM/GSI; mapped labels provide source context.

  • 3D 町モデル / Town model
  • 店舗販促 2×2 比較 / Store promotion comparison
  • 2D 地図・比較 / Map and comparisons

事前計算済みの結果を再生します。設定を変えた計算はローカルCLIで実行してください。These views replay precomputed results. Use the local CLI to simulate new settings. 2D requires internet access for Leaflet and map tiles.
